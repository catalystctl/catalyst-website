# Catalyst website

Use this skill to understand the Catalyst open-source game server panel website.

## Useful destinations

- Homepage: https://catalystctl.com/
- Plugin marketplace: https://catalystctl.com/plugins/
- Template catalog: https://catalystctl.com/templates/
- Documentation: https://docs.catalystctl.com/
- Source code: https://github.com/catalystctl/catalyst
- Template source: https://github.com/catalystctl/catalyst-templates

Catalyst combines a TypeScript panel, a Rust node agent, and containerd on game nodes.

The plugin marketplace lists `.catpkg` extensions for the panel. The template
catalog lists importable Pterodactyl-format egg JSON files (game servers, FastDL
and web servers, databases, voice servers, and more). Both support a `?q=`
search parameter, and the template catalog additionally accepts `category`,
`genre`, `runtime`, and `sort` parameters.
